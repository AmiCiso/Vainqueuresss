How VanQ Omni analyzes a URL ↓

VanQ Omni parses the URL text in your browser. It does not fetch the page, follow redirects, resolve DNS or check certificates.

  1. Validation: only http:// and https://; URLs with user:pass@ are rejected; hosts are normalized (case, trailing dot, numeric IP forms).
  2. Indicators: a fixed set of structural checks (lookalike names, raw IPs, ports, downloads, encoding, hosting type, nested destinations). Every report lists each one with its explanation.
  3. Nested destinations: URLs embedded in parameters, the path or the fragment are analyzed separately within fixed limits, and never visited.
  4. Scoring: indicators that describe the same underlying property are grouped and counted once at reduced weight. The 0 to 99 score is an uncalibrated sum, not a probability.
  5. Optional external lookup: Google Safe Browsing and URLhaus. A provider outage, missing key or rate limit is shown as such and never as “clean”.
